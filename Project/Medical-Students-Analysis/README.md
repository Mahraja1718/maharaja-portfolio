# Medical Students Dataset Analysis

## Project Overview
This project focuses on analyzing a medical students dataset using Python to explore student information, identify missing values, and understand patterns in the data.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Seaborn

## Project Workflow
1. Load and inspect the dataset
2. Handle missing values
3. Identify and handle duplicate records
4. Clean and preprocess data
5. Perform Exploratory Data Analysis (EDA)
6. Visualize patterns using Seaborn

## Project Files
- `medical_students_analysis.ipynb` – Python analysis notebook
- `dataset/` – Dataset used for analysis
