# Food Delivery Dataset Analysis

## Project Overview
This project analyzes food delivery data using Python to understand order patterns, delivery performance, customer ratings, and payment preferences.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow
1. Load and explore the dataset
2. Handle missing and invalid values
3. Remove duplicate records
4. Clean and preprocess the data
5. Perform Exploratory Data Analysis (EDA)
6. Create visualizations using Matplotlib and Seaborn
7. Identify meaningful insights

## Project Files
- `food_delivery_analysis.ipynb` – Python analysis notebook
- `dataset/` – Dataset used for analysis

Key findings and visualizations will be documented after reviewing the completed analysis.
