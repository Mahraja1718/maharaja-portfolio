# E-commerce Dataset Analysis

## Project Overview
This project focuses on analyzing an e-commerce dataset using Python to understand product information, customer purchasing patterns, and data quality.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy

## Project Workflow
1. Load and inspect the dataset
2. Identify missing values
3. Handle duplicate records
4. Clean and preprocess data
5. Perform Exploratory Data Analysis (EDA)
6. Analyze product and category information
7. Summarize key insights

## Project Files
- `ecommerce_analysis.ipynb` – Python analysis notebook
- `dataset/` – Dataset used for analysis
